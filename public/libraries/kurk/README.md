# Curated Excalidraw libraries

This directory contains a focused, offline-ready selection from the official [Excalidraw Libraries](https://libraries.excalidraw.com/) catalog. The source files are maintained in [excalidraw/excalidraw-libraries](https://github.com/excalidraw/excalidraw-libraries) and are distributed under the MIT license stated by that catalog.

The selection is bundled for Xcalidraw by Kurk and covers business, marketing, customer journeys, web and mobile wireframes, forms, people, flowcharts, and software architecture. Original library authors remain identified in the official catalog and repository history.
